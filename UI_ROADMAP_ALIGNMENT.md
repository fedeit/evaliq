These changes reflect the future-product direction from the roadmap. They should make the roadmap feel credible without implying every future project is already built.

- Done: `PrepBrief.jsx` changed the action from `Mark reviewed` to `Approve brief`.
- Done: `PrepBrief.jsx` now has real `Edit`, `Done editing`, and approval states.
- Done: `PrepBrief.jsx` now shows a trust banner: `Draft generated by EvalIQ. Manager reviews before use. Every claim links to a source.`
- Done: `Reports.jsx` changed `AI summary` to `Draft evidence summary`.
- Done: `Reports.jsx` now has `source-backed` and `manager review required` pills.
- Done: `UserSettings.jsx` now says raw prep briefs remain manager-facing by default.
- Pending: citation helper text is still not added.

#### UI Changes Needed

  - Suggested copy: `Draft generated by EvalIQ. Manager reviews before use. Every claim links to a source.`
- Done: make the prep brief editable from the `Edit` button while keeping citations and source links visible.

#### Current UI State

- Done: `PostMeetingLogger.jsx` now says notes seed `manager-owned review notes`.
- Done: `PostMeetingLogger.jsx` changed `Add to HR file` to `Save review evidence`.
- Pending: `EmployeeProfile.jsx` does not yet summarize review-ready evidence.
- Pending: there is not yet a review-readiness panel.

#### UI Changes Needed

- Done: replace `Seeds the next prep brief and the HR write-up at review time.`
- Done: replace the `Add to HR file` button.
- Pending: add a compact review-readiness panel to `PostMeetingLogger.jsx` or `Reports.jsx`.
  - Fields: last 1:1 note saved, action items captured, source-backed examples available, manager approval status.
- Pending: add a small `Review evidence` section under coaching history in `EmployeeProfile.jsx`.
  - Rows: strength example, concern example, open action item, source count.

#### Do Not Add

- Do not present HR narrative generation as current MVP.
- Do not add fully automated HR submission.
- Do not add PageUp, Workday, or BambooHR export as working current functionality unless clearly labeled future.

### Roadmap Theme 3: Lost Signals Gap

#### Current UI State

- Pending: `PrepBrief.jsx` has coaching questions, but not a clear `From last meeting` continuity section.
- Pending: `PostMeetingLogger.jsx` says saved notes will seed the next prep brief, but action carryforward is not explicit enough.
- Pending: `Reports.jsx` does not yet show continuity metrics.

#### UI Changes Needed

- Pending: add `Carried forward from last 1:1` in `EmployeeProfile.jsx`.
  - Fields: prior action item, owner, due date, status, `Included in next prep brief`.
- Pending: add `From last meeting` in `PrepBrief.jsx` before coaching questions.
  - Fields: previous action item, what changed since then, suggested follow-up.
- Pending: make post-save confirmation more specific in `PostMeetingLogger.jsx`.
  - Proposed copy: `This action item will appear in the next prep brief until closed.`
- Pending: add continuity metrics to `Reports.jsx`.

#### Do Not Add

- Do not add public benchmarks.
- Do not add director rollups as a main surface.
- Do not add raw voice-recording analysis.
- Do not add peer/360 feedback; it was explicitly deprioritized due to HR and political risk.
